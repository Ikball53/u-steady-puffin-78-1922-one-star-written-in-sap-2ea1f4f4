## One Star, Written in Sap

One one-star review, 203 characters, in a houseplant's voice: watered every Sunday whether thirsty or drowning, moved to the windowsill for one photo in March and never put back — 214 days of direct sun, and he still calls it 'good light.'

`main.py` writes the exact line (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
